# Dorama Bloom

App Android fofinho para organizar doramas, no estilo de uma lista tipo MyAnimeList: capas, temporadas e episódios, nota em corações (com meio coração), status, favoritos, sinopse, resenha, elenco, casal favorito, datas, estatísticas e temas diferentes para cada gênero.
Todos os símbolos são desenhados no próprio app. Tudo fica salvo no celular. Gere o APK em Actions > Build APK > Run workflow.
